# 《影之刃零》宿敌再战 Mod 使用说明

通过铃铛菜单，重新挑战已经击败过的 Boss。挑战只是临时的：结束后自动恢复存档，回到出发时的铃铛，游戏进度不会改变。

> 当前状态：功能已写完，**尚未在游戏里完整测试**。首次使用请按第 7 节的测试步骤进行。
>
> 适用版本：Steam 版《影之刃零》（测试时游戏版本 CL-302256）。

---

## 1. 一键安装

1. **完全退出游戏。**
2. 解压安装包，双击 **`安装宿敌再战Mod.bat`**。
3. 工具会自动在 Steam 库里查找游戏。没找到的话，点击：
   - **选择游戏程序…**：选 `PBZ.exe`（游戏目录下任意一个 `PBZ.exe` 都可以），或
   - **选择游戏文件夹…**：选游戏安装文件夹（一般是 `steamapps\common\PBZ`）。
4. 确认状态栏显示绿色的「游戏目录」，点击 **安装 / 更新**。
5. 看到「安装完成」后启动游戏即可。

安装工具会做这些事：

- 备份存档到游戏目录下的 `_rematch_backup\` 文件夹（可取消勾选）。
- 安装 UE4SS 框架（Mod 运行必需）。如果你已经装过 UE4SS，默认不覆盖；勾选后会更新框架，但保留你原有的 `mods.txt` 和 `UE4SS-settings.ini`。
- 安装本 Mod，自动识别你的存档文件夹并写入配置。
- 在 `mods.txt` 中启用本 Mod。

**更新**：用新版安装包再点一次「安装 / 更新」。你的 `config.lua` 设置、Boss 位置记录都会保留。

**如果双击 bat 没反应**：右键 `installer\installer.ps1` →「使用 PowerShell 运行」。

## 2. 安装后的文件

所有文件都在游戏目录下，没有修改任何游戏原文件。

| 位置 | 作用 |
|---|---|
| `platform\steam\dwmapi.dll` | UE4SS 加载器（Mod 框架入口） |
| `platform\steam\ue4ss\` | UE4SS 框架本体和设置 |
| `platform\steam\ue4ss\Mods\PBZBossRematch\` | 本 Mod |
| `platform\steam\ue4ss\Mods\PBZBossRematch\Scripts\config.lua` | 本 Mod 的配置（按键等） |
| `platform\steam\ue4ss\Mods\PBZBossRematch\data\` | 运行时数据：日志、存档快照、Boss 位置记录 |
| `_rematch_backup\` | 安装工具做的存档备份 |

UE4SS 使用的是 KintaroModding 发布的《影之刃零》专用包（v3.0.1-1195），MIT 许可证见 `platform\steam\ue4ss\LICENSE`。

## 3. 使用方法

1. 正常启动游戏、读取存档。
2. 走到任意铃铛，打开铃铛菜单。
3. 菜单底部会多出一个 **「宿敌再战」** 按钮，点击进入。
4. 先选择地图（括号里是该地图可挑战的 Boss 数量），再选择 Boss。
5. 菜单关闭后，你会被直接传送到 Boss 面前约 7 米处，面朝 Boss，Boss 刷出后屏幕上提示「挑战开始」。
6. 挑战结束后自动返回：
   - **胜利**：约 5 秒后返回。
   - **失败（角色死亡）**：约 7 秒后返回。
   - **主动退出**：按 `Home` 键，立即返回。
7. 返回后屏幕提示「已返回，进度未改变」，你会回到出发时的铃铛。

### 列表里显示哪些 Boss

- 只显示图鉴中已解锁的 Boss。
- 多阶段 Boss 的后续阶段（如「力者：石破天惊之态」）和教学战不单独列出，因为它们由第一阶段自动转入。
- 名字后面带「（未勘察）」的，表示 Mod 还没记录到这个 Boss 的具体位置。游戏地图是分块加载的，Boss 所在区域没加载时找不到它。所以选择后会先传送到该地图的一个铃铛，然后 Mod 在后台悄悄加载地图各处来定位 Boss（屏幕提示「正在定位 xx…」，角色不会移动），找到后再一次传送到 Boss 面前。第一次会多等几秒，之后就直接到位。
- 定位过程中顺便发现的其他 Boss 也会一起记录下来。平时你在地图里走动时，Mod 也会每 30 秒记录一次附近的 Boss。
- 名字后面带「（暂不支持）」的，表示整张地图都没找到它的刷怪点（通常是由过场动画或特殊空间生成的 Boss），选择后不会再传送。

## 4. 快捷键

| 按键 | 作用 | 何时生效 |
|---|---|---|
| `Home` | 退出挑战，恢复存档并返回出发铃铛 | 仅挑战中 |
| `End` | 一键击杀当前挑战的 Boss（测试用） | 仅挑战中 |
| `Ctrl + O` | 显示 / 隐藏 UE4SS 调试窗口（排查问题用） | 任何时候 |

注意避开的冲突：`Ctrl + F11` 是游戏全屏切换，`F10` / `~` 会打开游戏控制台。

按键可以在 `config.lua` 里修改，见第 5 节。

## 5. 配置（config.lua）

用记事本打开 `platform\steam\ue4ss\Mods\PBZBossRematch\Scripts\config.lua`，修改后重启游戏生效。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `ExitKey` | `"HOME"` | 退出挑战的按键 |
| `EnableKillKey` | `true` | 是否启用一键击杀，改成 `false` 关闭 |
| `KillKey` | `"END"` | 一键击杀的按键 |
| `VictoryReturnDelayMs` | `5000` | 胜利后多少毫秒返回 |
| `DefeatReturnDelayMs` | `7000` | 失败后多少毫秒返回 |
| `OnlyDiscovered` | `true` | 只显示图鉴已解锁的 Boss |
| `HiddenBossPatterns` | 见文件 | 不在列表中显示的条目 |
| `EntryLabel` | `"宿敌再战"` | 铃铛菜单按钮文字 |
| `SteamId` | 安装时自动填写 | 存档文件夹名（`ProjectPBZ\Saved\SaveGames\Steam\` 下的数字文件夹） |
| `GameRoot` | 安装时自动填写 | 游戏安装目录 |

可用的按键名称见 `platform\steam\ue4ss\Mods\Keybinds\Scripts\main.lua`，例如 `HOME`、`END`、`INS`、`DEL`、`PAGE_UP`、`PAGE_DOWN`、`F5` 等。

## 6. 存档安全机制

挑战不会影响你的正式进度，靠的是三层保护：

1. **挑战前做快照**：点击 Boss 后，Mod 先把主存档 `PBZSaveGame.sav` 复制到 `data\snapshot\`。
2. **挑战中禁止存档**：到达 Boss 处后，Mod 调用游戏自带的「存档否决」功能，挑战期间游戏不会写入存档。
3. **挑战后恢复并重新读档**：结束时把快照写回主存档，再让游戏重新读取它，内存里的状态也一起回到挑战前。

### 防崩溃

挑战开始时会写入 `data\challenge_state.lua`。如果挑战中途游戏崩溃或被强制关闭，下次启动游戏时 Mod 会发现这个文件，自动把快照恢复到主存档。**崩溃后请先正常启动游戏到主菜单，再读档。**

### 关于 Steam 云存档

如果启动时 Steam 提示云存档冲突，请选择 **本地文件**。

### 手动恢复存档（万一需要）

存档位置：`ProjectPBZ\Saved\SaveGames\Steam\<你的数字文件夹>\`

可用的备份：

| 位置 | 内容 |
|---|---|
| `_rematch_backup\saves_日期时间\` | 每次运行安装工具时的完整存档备份 |
| `platform\steam\ue4ss\Mods\PBZBossRematch\data\snapshot\` | 最近一次挑战前的快照 |
| 存档目录下的 `1RealTime\`、`2Hourly\`、`3Daily\` | 游戏自己的滚动备份，和主存档格式相同 |

恢复方法：**完全退出游戏**，把要恢复的 `.sav` 文件复制为存档目录下的 `PBZSaveGame.sav`（覆盖），再启动游戏。

## 7. 首次测试步骤

1. 启动游戏，按 `Ctrl + O` 打开 UE4SS 窗口，确认出现 `PBZBossRematch loaded` 和两行 `hook ... ok`。
2. 读档，在任意有 Boss 的地图停留约 30 秒，让 Mod 记录 Boss 位置。
3. 打开铃铛菜单，确认有「宿敌再战」按钮。
4. 选择一个当前地图里的 Boss。
5. 确认：菜单关闭、传送到铃铛、Boss 出现、屏幕提示「挑战开始」。
6. 按 `End` 击杀，等待自动返回。
7. 返回后确认进度没有变化。

任何一步出问题，记下是哪一步，查看日志：
`platform\steam\ue4ss\Mods\PBZBossRematch\data\rematch.log`

## 8. 已知限制

- 通过刷怪点直接刷出 Boss，**不会播放开场过场动画**。
- 一键击杀**没有死亡动画**，Boss 会直接被判定死亡。
- 挑战中**没有掉落和奖励**，挑战结束后一切恢复原状。
- 少数由过场动画或特殊空间生成的 Boss（例如断铃空间里的荒行子第二战）可能找不到刷怪点，选择后会提示「暂不支持」并自动返回。
- 游戏更新后，UE4SS 或本 Mod 可能需要更新。

## 9. 卸载

**推荐**：运行 `安装宿敌再战Mod.bat`，点击 **卸载**。

- 如果检测到有挑战没有正常结束，工具会提醒你先进一次游戏，让 Mod 自动恢复存档。
- 如果 UE4SS 是本工具安装的，会询问是否一起删除。装了其他依赖 UE4SS 的 Mod 时请选「否」。

**手动卸载**（先完全退出游戏）：

- 只卸载本 Mod：删除 `platform\steam\ue4ss\Mods\PBZBossRematch\` 文件夹，或在 `platform\steam\ue4ss\Mods\mods.txt` 里把 `PBZBossRematch : 1` 改成 `PBZBossRematch : 0`。
- 卸载全部 Mod 框架：删除 `platform\steam\dwmapi.dll` 和 `platform\steam\ue4ss\` 文件夹。
